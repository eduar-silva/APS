## APS - Análise e Projeto de Sistemas

**Projeto APS** é um projeto acadêmico desenvolvido como atividade prática supervisionada. Este projeto integra conceitos de engenharia de software, boas práticas de desenvolvimento e metodologias de gestão de projeto para resolver um problema específico ou implementar uma solução inovadora.

---

## 👥 Para Quem?

- **Público-alvo:** Comunidade acadêmica, instrutores, avaliadores e colaboradores
- **Stakeholders:** Equipe de desenvolvimento, orientadores e usuários finais da aplicação

---

## 📍 Onde?

- **Localização do Projeto:** https://eduar-silva.github.io/APS/
- **Ambiente de Execução:** Pode ser executado localmente em máquinas com as dependências necessárias
- **Plataforma de Distribuição:** GitHub Pages

### Motivação:
Este projeto surge da necessidade de sanar dúvidas de calouros sobre a universidade, desde localização até financeiro, além de visar a demonstração da aplicação prática de conceitos teóricos aprendidos em sala de aula.
