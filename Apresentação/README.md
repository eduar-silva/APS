## 💡 O projeto em 30 segundos

> O **Acolhida UDF** é uma proposta de plataforma de orientação para estudantes que estão começando sua jornada universitária. A ideia é reunir, em um só lugar, informações úteis sobre setores, localizações, serviços e dúvidas frequentes, facilitando os primeiros contatos dos calouros com o ambiente acadêmico.

Este repositório reúne o protótipo da interface e materiais produzidos durante a disciplina de **Análise e Projeto de Sistemas**.

## 🎯 O problema que queremos resolver

Ingressar na universidade envolve descobrir onde ficam os setores, a quem recorrer e como resolver questões acadêmicas e administrativas. Nem sempre essas informações são fáceis de encontrar logo nos primeiros dias.

| Dificuldade do calouro | Resposta proposta pelo Acolhida |
| :--- | :--- |
| Não saber onde ficam os principais setores | Apresentar locais e referências de localização no campus |
| Ter dúvidas sobre matrícula e documentos | Reunir orientações iniciais e perguntas frequentes |
| Não saber onde buscar atendimento | Exibir os serviços oferecidos pelos setores |
| Precisar encontrar um local rapidamente | Oferecer busca por termos como "biblioteca" ou "secretaria" |
| Encontrar informações dispersas | Concentrar conteúdos essenciais em uma interface simples |

**Público principal:** estudantes ingressantes da UDF, com utilidade também para outros membros da comunidade acadêmica.

## 🧭 Uma interface para orientar o primeiro contato

O protótipo web apresenta recursos que ajudam o estudante a localizar informações básicas:

| Recurso | O que demonstra |
| :--- | :--- |
| **Página inicial** | Apresentação do Acolhida e acesso à busca |
| **Busca por locais** | Filtragem dos setores por palavras-chave |
| **Cartões de setores** | Nome, serviço, referência de localização e horário exibido no protótipo |
| **Guia de setores** | Atalhos para consultar os principais espaços |
| **Perguntas frequentes (FAQ)** | Orientações sobre matrícula, carteirinha estudantil e Wi-Fi |

### Locais apresentados no protótipo

- **Secretaria Acadêmica:** matrículas, documentos e solicitações.
- **Biblioteca:** acervo, empréstimos e espaços de estudo.
- **Coordenação:** orientações acadêmicas.
- **Laboratórios:** ambientes de atividades práticas.
- **Cantina:** alimentação e convivência.

### Como explorar

1. [Abra o protótipo publicado no GitHub Pages](https://eduar-silva.github.io/APS/).
2. Digite um setor no campo de pesquisa, como `biblioteca` ou `secretaria`.
3. Consulte os cartões e abra os detalhes de um local.
4. Utilize os atalhos de setores e navegue até **Dúvidas** para explorar o FAQ.

> [!NOTE]
> O Acolhida é um **projeto acadêmico em formato de protótipo**. Nomes de blocos, salas, horários e demais informações exibidas na interface são dados demonstrativos e devem ser validados com a instituição antes de qualquer uso oficial. A interface não realiza consultas em tempo real aos sistemas da UDF.

## ▶️ Como visualizar localmente

Como o protótipo utiliza tecnologias web estáticas, ele pode ser aberto diretamente no navegador:

```bash
git clone https://github.com/eduar-silva/APS.git
cd APS
```

Em seguida, abra o arquivo `docs/index.html` no navegador.

Não é necessário instalar um servidor de backend para visualizar a interface estática.

## 🎤 Roteiro sugerido para apresentação · 5 minutos

| Tempo | Foco | Mensagem principal |
| :--- | :--- | :--- |
| **0:00–0:45** | Problema | Calouros podem ter dificuldades para localizar setores e encontrar informações essenciais |
| **0:45–1:30** | Proposta | O Acolhida reúne orientações em uma plataforma acessível |
| **1:30–3:00** | Demonstração | Mostrar a pesquisa, os setores e o FAQ no protótipo |
| **3:00–4:00** | Análise e projeto | Explicar como os requisitos e a modelagem apoiaram a proposta |
| **4:00–5:00** | Limites e próximos passos | Diferenciar o protótipo da futura validação com a universidade |

> **Sugestão de abertura:** “Entrar na universidade é uma experiência nova, mas encontrar uma sala, um setor ou uma informação importante não deveria ser uma dificuldade. O Acolhida surgiu para tornar esse começo mais simples.”

## 🚧 O que já está demonstrado — e o que ainda precisa evoluir

| Situação | Escopo |
| :--- | :--- |
| **Demonstrado** | Interface web estática, busca por setores, cartões de locais, atalhos e perguntas frequentes |
| **A validar** | Localizações, horários de atendimento e informações institucionais oficiais |
| **Próximos passos possíveis** | Testes com estudantes, aprimoramento da experiência e estudo de atualização dos dados |

O protótipo é uma demonstração da proposta acadêmica; **não representa um sistema institucional oficialmente implantado pela UDF**.
