# MVP — Sistema de Acolhida aos Calouros da UDF
INTEGRANTES:
## Visualização

Abra `ProjetoAPS/index.html` em qualquer navegador moderno.

## Funcionalidades do MVP

- Busca interativa por nome de setor, sala ou serviço.
- Lista responsiva dos principais locais do campus.
- Detalhes de localização, horários e contatos introdutórios.
- Navegação rápida para setores.
- FAQ interativo.
- Layout adaptável para celulares, tablets e desktops.

## Tecnologias

HTML5, CSS3 e JavaScript básico, sem dependências externas.
